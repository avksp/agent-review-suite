# Skills and host use

[Русский](../ru/guides/skills.md)

Skills provide bounded review guidance using supplied evidence. They do not
authorize tests, network, model dispatch, installation or workflow transitions. Select
solution, implementation, security or product review deliberately. Each entrypoint
loads only its relevant references. The current plugin is guidance-only.
Codex uses `.codex-plugin/plugin.json` and a repo-local marketplace. Claude Code
has separate plugin metadata. Other hosts may consume SKILL.md through an existing
documented feature; inspect `adapters/<host>/projection.json`. All 12 ARS host
projections are UNQUALIFIED. Do not edit global host settings from this repository.
See [adapter policy](../reference/adapters.md).
