# ADR 0001 · Независимость ядра от вызывающей системы

[English](../../architecture/adr-0001-boundaries.md)

Используйте самостоятельный версионированный контракт запросов и отчётов.
Вызывающая сторона отвечает за запуск, бюджет, повторы, записи жизненного
цикла и приёмку. Она может (MAY) использовать свой инструмент управления процессом
через его поддерживаемые интерфейсы.

Например, скрипт и инструмент управления процессом могут передать одинаковые байты валидатору ARS.
Каждая вызывающая сторона применяет к результату свои правила. Неудачное ревью
и недоступность хоста требуют разных решений. Перед повтором вызывающей стороне
необходимо (MUST) выяснить результат попытки с неизвестным исходом.

Будущему преобразователю форматов следует (SHOULD) точно сопоставлять поля
для конкретного потребителя. Переносимый контракт остаётся независимым от
состояния и правил хоста.
