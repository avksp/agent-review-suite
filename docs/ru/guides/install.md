# Установка

[English](../../guides/install.md)

Используйте Python от 3.11 до 3.15. Создайте и активируйте виртуальное
окружение. Выполните `python -m pip install -e .` из рабочего дерева или
установите полученный локальный wheel командой
`python -m pip install /path/to/agent_review_suite-0.1.0-py3-none-any.whl`.
Импортируйте `agent_review_suite` и проверьте `__version__`.

Используйте [ограниченный CLI](../reference/validation.md) на подходящих
системах Linux или macOS. На Windows вызовите [Python API для байтов](../reference/request-report.md).
Для 0.1.0 используйте исходники или предоставленный wheel.
