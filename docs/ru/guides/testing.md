# Проверка качества

[English](../../guides/testing.md)

Установите зафиксированные зависимости разработки. Запустите тесты из
рабочего дерева, добавив `src` в `PYTHONPATH`.

```sh
PYTHONPATH=src python -B -m unittest discover -s tests -v
```

Тесты покрывают лимиты контрактов, доверенные привязки, отказы ввода,
коды возврата и границы архивов. Например, для чужого идентификатора
покрытия ожидается код 3. При повторной строке покрытия в том же входе
ожидается код 2. Запустите Ruff и mypy перед сборкой wheel, sdist и plugin
ZIP. Проверьте состав архивов и запустите валидатор в чистой установке wheel.

Для каждой заявленной проверки укажите ОС, интерпретатор, точные исходники и
артефакты. Учитывайте локальные тесты отдельно от 15 ячеек CI. Сохраняйте
неудачные попытки и неизвестный расход как null. Сравнивайте расход только
для эквивалентной работы.
