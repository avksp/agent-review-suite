# Подготовка поставки

[English](../../guides/releasing.md)

1. Соберите wheel, архив исходников (sdist) и ZIP плагина из одного дерева.
   Запишите коммит Git и ID дерева. Сохраните хеши архивов и списки файлов.
2. Проверьте публичные исходники и архивы на частные данные. Каждый архив
   обязан (MUST) содержать те же три схемы v1. Синтетические примеры могут
   входить только в sdist.
3. Установите wheel в чистое окружение. Запустите проверки установленных
   API и CLI. Сохраните локальные доказательства для независимого финального
   аудита и завершения.
4. Откройте PR в защищённую ветку. Проверьте, что дерево будущего merge
   совпадает с проверенным. Все 15 заданий CI должны (MUST) пройти на
   ревизии будущего merge. Повторите проверку при изменении базы или головы PR.

Например, вычислите SHA-256 схемы ожидаемых привязок в wheel, sdist и ZIP
плагина. Три хеша должны (MUST) совпасть.

## Публикация в PyPI

Укажите в PyPI Trusted Publisher репозиторий `avksp/agent-review-suite`,
файл `publish.yml` и окружение `pypi`.
См. [Trusted Publishing](https://docs.pypi.org/trusted-publishers/creating-a-project-through-oidc/).

1. Дождитесь прохождения всех 15 заданий CI на коммите выпуска в `main`.
2. Для проверки кандидата запустите **Publish to PyPI** вручную на `main`.
   Запуск сохранит wheel и архив исходников из этого CI. Проверьте имена
   файлов и хеши. Для проверки метаданных используйте
   `python -m twine check --strict`.
3. Владелец релиза обязан (MUST) разрешить публикацию. Создайте стабильный
   GitHub Release с защищённым тегом, который соответствует версии пакета
   и указывает на проверенный коммит. Например, тег `v0.1.0` для версии `0.1.0`.
4. Публикация GitHub Release запускает загрузку. Workflow проверяет тег,
   коммит, результат CI и SHA-256. Он загружает те же wheel и архив
   исходников через окружение `pypi`. Поставляйте ZIP плагина отдельно.
5. Проверьте файлы на PyPI и установите опубликованную версию в чистом
   окружении. Зафиксируйте результат.

Если срок хранения артефактов CI истёк, сначала повторите все задания
для коммита выпуска.
