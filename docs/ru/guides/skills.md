# Скиллы и хосты

[English](../../guides/skills.md)

Скиллы дают bounded guidance по предоставленным доказательствам. Они не
разрешают тесты, сеть, вызов моделей, установку или native transitions ALK.
Выбирайте solution/implementation/security/product review по задаче. Entry point
читает только нужные references. Текущий plugin — guidance-only.
Для Codex есть manifest и локальный marketplace; для Claude Code — отдельные
метаданные. Другие хосты используют свои документированные SKILL.md-возможности.
Все 12 ARS projections имеют UNQUALIFIED. Глобальные настройки хостов не меняются.
См. [адаптеры](../reference/adapters.md).
