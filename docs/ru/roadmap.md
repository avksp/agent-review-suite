# Дорожная карта

[English](../roadmap.md)

| Версия | Область | Состояние |
| --- | --- | --- |
| 0.1.0 | Независимые контракты, ограниченный ввод и устанавливаемые пакеты | Реализовано. Публикация пакета отслеживается отдельно |
| 0.2.0 | Технические пакеты, пакеты безопасности и пилот безопасного сбора доказательств | DRAFT |
| 0.3.0 | Продуктовая оценка вариантов по заданным целям и данным | DRAFT |
| 0.4.0 | Проверка конкретных ролей хостов и необязательная интеграция с внешним процессом | DRAFT |

Для каждой будущей версии нужны ограниченное исследование, ревью, проверки и доказательства поставки.
SHA предыдущего выпуска становится известен при фактической поставке. Метрики
DORA и расписание ведёт внешняя система поставки. Интеграцию с внешним процессом можно
отложить, сохранив проверенные самостоятельные роли хостов.

В будущих версиях можно автоматизировать выбор пакетов, запуск ревьюверов
и сведение замечаний.
