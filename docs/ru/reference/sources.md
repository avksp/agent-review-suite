# Источники методик

[English](../../reference/sources.md)

Источники — материал независимой оценки, не исполняемая политика пакета:
Cloudflare — методика; OWASP — тематические рекомендации; cc-safety-net — границы
host guard; Tencent — optional scanners; Claude-Red — разрешённые lab cases;
BLA — только adversarial inputs. Приватные pinned snapshots и model reports не
публикуются. Upstream code/text не включать без per-file license/attribution review.
Cloudflare confirmed/execution отличается от static proof. OWASP не scanner и не
сертификат. Bootstrap не заявляет detection или token-saving benchmark.
Ссылки: https://github.com/cloudflare/security-audit-skill,
https://github.com/OWASP/CheatSheetSeries, https://github.com/kenryu42/cc-safety-net,
https://github.com/Tencent/AI-Infra-Guard, https://github.com/SnailSploit/Claude-Red,
https://github.com/qybaihe/bla.
