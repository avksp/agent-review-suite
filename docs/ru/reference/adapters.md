# Проекции хостов

[English](../../reference/adapters.md)

Основной I/O-контракт независим от хостов. Проекции содержат только discovery/
delivery notes и точный qualification status; исходники хостов не меняются.
Подготовлены Codex/Claude metadata и SKILL.md; другие хосты могут получать задания
только через свои поддерживаемые возможности. Все 12 проекций ARS имеют статус UNQUALIFIED.
Проверенная версия указана как null. Проекции не заявляют принудительных ограничений.
Квалифицируйте каждый хост и версию по прямым доказательствам. OpenCode 1.x/2.x
проверять отдельно. Наследование: project → profile → audit → assignment; модели/
effort локальные, не defaults. Reserve только при доказанной pre-dispatch
недоступности и заранее допустимом route. Timeout/lost response/adverse verdict
требуют reconciliation/remediation; availability не означает пригодность к задаче.
