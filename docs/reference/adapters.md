# Host adapter projections

[Русский](../ru/reference/adapters.md)

The canonical input/output contract is independent of hosts. Per-host projections
contain only documented discovery/delivery notes and explicit qualification status.
No host source is modified. Codex/Claude metadata and SKILL.md files are prepared;
manual delivery to other hosts is possible only through their supported features.
All 12 ARS projections have status UNQUALIFIED. The tested version is null
and each projection makes no enforcement claim. Qualify each host and version
with direct evidence. OpenCode 1.x and 2.x require
separate checks. Routing inheritance is project → profile → audit → assignment;
concrete adapter/model/effort stays local, never product defaults.
A reserve applies only on confirmed pre-dispatch unavailability with an already
approved eligible route. Lost response, timeout and adverse review require their
own reconciliation/remediation. Host/model availability is not task suitability.
